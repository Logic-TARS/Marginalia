# Reader Boundary Tests

## Running Tests
```bash
cd frontend
npm install
npx playwright install chromium  # or use system Chrome via channel: 'chrome'
npx playwright test
```

## Test Tags
- `@smoke` — verifies the EPUB fixture loads correctly and desktop immersive controls can be restored
- `@boundary.forward` — cross-section forward navigation lands on page 1 of new chapter
- `@boundary.backward` — cross-section backward navigation lands on last page of prior chapter
- `@boundary.intra` — same-section navigation advances exactly +1/-1 page
- `@mobile` — checks common mobile widths, safe-area reader controls, horizontal swipe pagination, configurable immersive reader chrome, modal reader tools, and touch-style text highlighting
- `navigation.spec.js` — verifies that reading and creation are entered only from the home screen and that browser history returns to, and can restore from, the home screen
- `import-ux.spec.js` — verifies first-open download feedback, IndexedDB EPUB reuse, content-hash invalidation, and storage-quota fallback
- `service-worker-cache.spec.js` — verifies that versioned app caches are separate from the stable EPUB cache
- `reader-typography.spec.js` — verifies reader font/size controls, CFI-stable reflow, keyboard-wheel zoom synchronization, local preference recovery, 44px touch targets, and target-width overflow guards
- `tts-player.spec.js` — mocks all TTS/audio I/O and verifies play/pause, generated-segment waiting, automatic next segment, forced CFI following, temporary highlight/underline lifecycle, latest-position navigation queuing, navigation locking, visual grouping, localStorage recovery, and chapter-switch cleanup
- `visual-polish.spec.js` — checks the polished library cards and creation workflow at 360/390/768/1000/1440 widths, including semantic structure and horizontal-overflow guards

## Fixture
The test fixture (`tests/fixtures/multichapter.epub`) is generated by `tests/fixtures/build-fixture.mjs`.
It contains 3 chapters, each ≥220 paragraphs (~50KB), rendered at 1000×700 viewport.
**Do NOT regenerate the fixture unless the content changes** — it is committed as a frozen binary.
The generator uses fixed ZIP timestamps (1980-01-01) for byte-reproducible output.

## Escalation
If the wrap-guard in `navigatePage` does NOT eliminate the cross-section page skip
(after 3 consecutive Playwright runs where `displayed.page !== 1` for forward cross-section),
escalate to patching `frontend/epub.min.js` with an offset-annotated patch.
See `.omo/plans/fix-chapter-boundary-page-skip.md` for details.
